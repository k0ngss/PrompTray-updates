# PrompTray

Windows x64 本地 Markdown 提示词库，提供原生桌面程序与独立 CLI。
桌面程序为 `PrompTray.exe`，命令行程序为 `PrompTray-cli.exe`。开发阶段不提供旧文件名兼容包或启动别名；旧开发版请关闭程序后手动安装新版，原提示词库和个人配置保留。

## 下载与使用

前往 [最新版本](https://github.com/k0ngss/PrompTray-updates/releases/latest) 下载 `PrompTray-Setup-版本.exe` 安装版，或下载 Windows x64 ZIP 便携版。安装版默认安装到当前用户 `%LOCALAPPDATA%\Programs\PrompTray`，不需要管理员权限，提供开始菜单、可选桌面快捷方式和系统卸载入口。
已有便携版可选择原程序目录安装，原库会备份并保留；若安装到新目录，请先备份并复制自己的 `library/`。
提示词保存在程序旁的 `library/`，文件变化自动刷新。右键点击提示词可编辑、重命名或删除；右键点击分类可新建提示词、新建子分类、重命名或删除空分类，也可用菜单键或 Shift+F10 打开菜单。左侧“最近删除”保留最近 5 条删除记录，每条可直接恢复到原分类，保留正文、变量和 ID，同名文件不覆盖。删除 MD 仍进入 Windows 回收站；旧软件回收站完整保留，有旧记录时从分类旁“···”菜单恢复。CLI 使用方法：`PrompTray-cli.exe --help` 或 `PrompTray-cli.exe api`。

顶部“版本更新”展示版本与更新说明，每次启动自动静默检查，不提供关闭开关，只提示新版，不自动下载。页面仅保留一个检查更新入口。
支持导出与导入分享：单条提示词导出 Markdown，分类与全库导出 ZIP，完整保留变量设置与分类层级。左侧分类区“···”菜单提供导入和导出全部入口，也可拖入一个 MD/ZIP；导入先预览，默认新建可改名的独立分类，也可选择已有分类。同名提示词自动另存，原内容不覆盖。
支持跳过版本、下载进度和取消；点击“下载并安装”后校验大小与 SHA-256，校验通过即自动关闭程序并安装，无需再次点击。
编辑中的草稿保持原状，保存或取消编辑后自动继续安装；等待时可取消安装。关闭浮层不打断下载或自动安装。安装版使用校验后的安装器升级，便携版只替换两个 EXE；两者均备份并重新打开原提示词库。卸载保留 library、回收站、个人设置和恢复备份。
也可以退出应用后手动覆盖程序文件，务必保留自己的 `library/`。

## 本仓库内容

此仓库提供公开安装下载与在线更新清单。源码在单独的私有仓库维护。
Release 附件为安装 EXE、便携 ZIP、update.json 与 SHA256SUMS.txt。公开包仅含固定示例，不含开发者个人提示词。

程序及附带依赖的许可证见 ZIP 中的 LICENSE 与 THIRD_PARTY_NOTICES.txt。
